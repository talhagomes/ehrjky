# Журнал проверки изменения объекта TikTok Ads

Дата: 25 октября 2026 года  
Кабинет: `<имя кабинета>` (`<aadvid>`)  
Кампания: `<campaign_id>`

## Проверенная операция

В штатном редакторе TikTok Ads Manager выполнено обратимое переименование кампании:

1. Исходное имя: `<исходное имя кампании>`.
2. Временное имя: `TTAds Hub mutation test 2026-10-25`.
3. Нажата штатная кнопка `Submit`.
4. После перезагрузки списка временное имя отображалось в строке кампании.
5. Кампания повторно открыта в редакторе, исходное имя возвращено и отправлено.
6. После перезагрузки списка подтверждено исходное имя `<исходное имя кампании>`.

Результат: изменение имени через интерфейс работает, сохранение происходит на стороне TikTok, возврат исходного состояния подтвержден. Статус, бюджет, расписание и платежные данные во время этого теста не менялись.

## Что доказал тест для расширения

- Расширение может открывать штатный редактор конкретной кампании и управлять полем имени через DOM-адаптер.
- После `Submit` результат нужно проверять повторным чтением списка, потому что успешное нажатие само по себе не доказывает сохранение.
- Для быстрой массовой операции в загруженном модуле найден отдельный endpoint `/api/v3/i18n/overture/campaign/batch_update/name/` и проверочный endpoint `/api/v3/i18n/overture/campaign/batch_update/name/check/`.
- В модуле имя передается как `name_map`; идентификатор элемента — `campaign_id`; новое значение — поле `name`.
- Мутационные запросы модуля добавляют `risk_info`: `cookie_enabled`, `screen_width`, `screen_height`, `browser_language`, `browser_online`, `timezone_name`.

## Граница доказанности

Фактический HTTP body штатного редактора во время UI-теста не перехватывался. Поэтому контракт bulk-endpoint отмечен как обнаруженный в актуальном bundle, а UI-переименование — как проверенное фактической операцией. Перед автоматическим вызовом bulk-endpoint нужно один раз снять полный запрос на тестовой кампании или выполнить controlled probe с последующим чтением результата.

Снимок метрик и биллинга на момент теста в публичную сборку не включён (реальные данные кабинета).
